# Build engineering handoff

The source audit flagged duplicate file-local C++ helpers in the default Unreal unity build and a Win64 package containing only Arena. The Eidolon module now compiles each translation unit separately. The opt-in [Win64 campaign prototype](../windows-campaign-package.md) cooks the manifest written by the authored map generator and starts in Valdris using a separate save slot. The routine Arena package entry point stays available.

PowerShell 7.4.11 parsing and simulated command execution passed, including paths containing spaces, invalid manifests and missing maps. The campaign generator's offline check validates every layout, and its manifest verification rejects missing and empty map files. Use a licensed UE 5.6 host for C++ compilation, actual commandlet generation, UAT cook, boot, and keyboard/controller playtest.
